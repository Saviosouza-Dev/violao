# Primeiros Acordes — Cartilha do Aluno

Material de apoio para aulas de violão iniciante, em página única.
Feito para o aluno abrir no celular ou no computador, sem instalar nada.

**Acesse aqui:** https://saviosouza-dev.github.io/violao/

## O que tem dentro

- As partes do violão
- Postura correta
- Suas mãos: esquerda e direita
- O braço, as casas e o nome das cordas
- Afinar o violão
- Como ler um diagrama de acorde
- Seus primeiros 4 acordes
- Exercícios de troca de acordes
- Seu primeiro padrão de ritmo
- Dúvidas frequentes

## Como funciona

Todo o conteúdo está em `index.html` — um arquivo só, sem dependências além
das fontes do Google Fonts. Layout responsivo (celular, tablet e desktop) e
folha de estilo para impressão, caso o aluno prefira o material em papel.

## Para editar

Abra `index.html` em qualquer editor, salve e publique:

```bash
git add .
git commit -m "Descreva a alteração"
git push
```

O GitHub Pages atualiza o site em cerca de um minuto.
